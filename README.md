# 🚀 Featured Projects

### 🔹 GrievSetu — AI-Assisted Grievance Management System

An AI-assisted platform designed to streamline grievance submission, classification, routing, and tracking.

**Tech:** React.js • FastAPI • TensorFlow/Keras • BiLSTM • CNN • MySQL • SQLAlchemy • JWT

- Built separate Citizen and Admin dashboards for grievance management
- Developed a multimodal classification pipeline using **BiLSTM for text** and **CNN with CBAM for images**
- Implemented automated grievance routing, priority assignment, and SLA tracking
- Research based on the project was accepted at the **ICT4SD International Conference**

---

### 🔹 Repo-Pilot — GitHub RAG for Python Repositories

A RAG-based application that allows users to interact with Python GitHub repositories using natural language.

**Tech:** Python • FastAPI • React.js • ChromaDB Cloud • Groq API • Llama 3.3 • Sentence Transformers • GitPython

- Built an AST-based indexing pipeline to extract functions, classes, and async functions
- Generated and stored embeddings for semantic retrieval
- Integrated Llama 3.3 with semantic search and symbol lookup
- Added source references to improve response transparency
- Supports GitHub repository cloning and multi-repository indexing
